WEEK 1 - STATIC WEB PAGE PROJECT

Files:
- index.html: Semantic page structure and simple client-side form validation.
- style.css: Layout, colors, spacing, and responsive styles.
- Week_1_Internship_Report.docx: Word report describing the approach and challenges.

How to run:
1. Extract the ZIP file.
2. Open index.html in a modern web browser.
3. Resize the browser or use mobile view to test the responsive layout.

Note:
This is a static front-end demonstration. The form validates the entered details in the browser,
but it does not upload files or save submissions to a server.
